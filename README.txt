CCNA 200-301 Study Desk
=======================

Open index.html in any modern browser. No server, build step or internet connection is needed.

Files
-----
index.html               Page shell (sidebar, header, main area)
css/styles.css           All styling, themes, layouts and dialogs
js/app.js                Application code and all content:
                         - 29 objectives with sub-objectives and study notes
                         - 1,400 quiz questions, 343 flashcards, 52 acronyms
                         - 134 PBQs, 40 configuration labs, subnet calculator
                         - 10 Packet Tracer lab guides (Packet Tracer Labs page)
packet-tracer-labs/      The same 10 Packet Tracer labs as plain text:
                         guide plus per-device config files (Packet Tracer's .pkt
                         format cannot be generated, so you build and save your own)

Progress, settings and lab completion are stored in your browser (localStorage).
Hosting: upload the whole folder to any static host (GitHub Pages, Netlify, S3).
