CCNA LAB 01: VLANs, 802.1Q Trunking and Router-on-a-Stick
Exam objectives: 2.1.b · 2.2.a · 2.4 · 1.3
Goal: Segment two departments into VLANs, trunk them to a router, and route between VLANs using sub-interfaces.

HOW TO USE IN PACKET TRACER
===========================
1. Place the devices below and cable them as listed (Automatic cable type is fine).
2. Configure the PC and server IP settings from the addressing table.
3. Open each device CLI tab and try the tasks yourself first.
4. Compare with the SOLUTION CONFIGS or paste them (enable, then configure terminal, then paste).
5. Save your own .pkt file from Packet Tracer (File > Save).

DEVICES
=======
- R1: Cisco 2911 router
- SW1: Cisco 2960-24TT switch
- PC1, PC2: PC-PT

CABLING
=======
- PC1 Fa0 to SW1 Fa0/1
- PC2 Fa0 to SW1 Fa0/2
- SW1 Gi0/1 to R1 Gi0/0

TOPOLOGY
========
PC1 --Fa0/1--+
               SW1 --Gi0/1====Gi0/0-- R1
PC2 --Fa0/2--+

ADDRESSING
==========
- PC1 | Fa0 | 192.168.10.10/24 | GW 192.168.10.1 (VLAN 10)
- PC2 | Fa0 | 192.168.20.10/24 | GW 192.168.20.1 (VLAN 20)
- R1 | Gi0/0.10 | 192.168.10.1/24 | dot1Q 10
- R1 | Gi0/0.20 | 192.168.20.1/24 | dot1Q 20
- R1 | Gi0/0.99 | 192.168.99.1/24 | dot1Q 99 native
- SW1 | VLAN 99 | 192.168.99.2/24 | GW 192.168.99.1

TASKS
=====
1. Create VLANs 10 (SALES), 20 (ENG) and 99 (MGMT) on SW1.
2. Put Fa0/1 in VLAN 10 and Fa0/2 in VLAN 20 as access ports with PortFast.
3. Configure Gi0/1 as a trunk: native VLAN 99, allowed VLANs 10, 20, 99.
4. Create the three R1 sub-interfaces with encapsulation dot1Q.
5. Give SW1 a management SVI and default gateway.
6. Ping from PC1 to PC2 and to the SW1 management address.

VERIFICATION
============
- SW1: show vlan brief
- SW1: show interfaces trunk
- R1: show ip interface brief
- R1: show ip route
- PC1: ping 192.168.20.10

CHALLENGE
=========
Change the trunk native VLAN on SW1 only to 1 and read the CDP native VLAN mismatch messages. Then fix it.

SOLUTION CONFIGS
================

--- SW1 ---
hostname SW1
vlan 10
 name SALES
vlan 20
 name ENG
vlan 99
 name MGMT
interface fa0/1
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
interface fa0/2
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast
interface gi0/1
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
interface vlan 99
 ip address 192.168.99.2 255.255.255.0
 no shutdown
ip default-gateway 192.168.99.1

--- R1 ---
hostname R1
interface gi0/0
 no shutdown
interface gi0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface gi0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
interface gi0/0.99
 encapsulation dot1Q 99 native
 ip address 192.168.99.1 255.255.255.0
