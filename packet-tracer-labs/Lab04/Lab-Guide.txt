CCNA LAB 04: IPv4/IPv6 Addressing and Static Routing with Floating Backup
Exam objectives: 1.4 · 3.1 · 3.2.a · 3.2.b · 3.2.d
Goal: Dual-stack three routers with static routes and a floating backup path.

HOW TO USE IN PACKET TRACER
===========================
1. Place the devices below and cable them as listed (Automatic cable type is fine).
2. Configure the PC and server IP settings from the addressing table.
3. Open each device CLI tab and try the tasks yourself first.
4. Compare with the SOLUTION CONFIGS or paste them (enable, then configure terminal, then paste).
5. Save your own .pkt file from Packet Tracer (File > Save).

DEVICES
=======
- R1, R2, R3: Cisco 2911
- PC1, PC3: PC-PT

CABLING
=======
- PC1 to R1 Gi0/0
- R1 Gi0/1 to R2 Gi0/0
- R2 Gi0/1 to R3 Gi0/0
- R3 Gi0/1 to PC3
- R1 Gi0/2 to R3 Gi0/2 (backup)

TOPOLOGY
========
PC1--R1==R2==R3--PC3
      \_________/
      (backup link, Gi0/2)

ADDRESSING
==========
- PC1 | Fa0 | 192.168.1.10/24 | GW 192.168.1.1; IPv6 2001:db8:1::10/64, GW FE80::1
- PC3 | Fa0 | 192.168.3.10/24 | GW 192.168.3.1; IPv6 2001:db8:3::10/64, GW 2001:db8:3::1
- R1 Gi0/1 / R2 Gi0/0 | 10.0.12.0/30 | 2001:db8:12::/64
- R2 Gi0/1 / R3 Gi0/0 | 10.0.23.0/30 | 2001:db8:23::/64
- R1 Gi0/2 / R3 Gi0/2 | 10.0.13.0/30 | 2001:db8:13::/64 | backup

TASKS
=====
1. Configure all IPv4 and IPv6 addresses. Use EUI-64 on R1 Gi0/0 with link-local FE80::1.
2. Enable ipv6 unicast-routing on all routers.
3. Configure primary static routes over R2 and floating routes (AD 5) over the backup link.
4. Add a default route on R3 with a floating backup.
5. Verify show ip route and show ipv6 route, then fail R2 and watch the backup install.

VERIFICATION
============
- R1: show ip route static
- R1: show ipv6 interface brief (note the EUI-64 address)
- R1: show ipv6 route
- PC1: ping 192.168.3.10
- PC1: ping 2001:db8:3::10

CHALLENGE
=========
Shut down both R2 interfaces. Confirm that the floating routes (AD 5) install on R1 and R3 and that pings still succeed.

SOLUTION CONFIGS
================

--- R1 ---
hostname R1
ipv6 unicast-routing
interface gi0/0
 ip address 192.168.1.1 255.255.255.0
 ipv6 address 2001:db8:1::/64 eui-64
 ipv6 address fe80::1 link-local
 no shutdown
interface gi0/1
 ip address 10.0.12.1 255.255.255.252
 ipv6 address 2001:db8:12::1/64
 no shutdown
interface gi0/2
 ip address 10.0.13.1 255.255.255.252
 ipv6 address 2001:db8:13::1/64
 no shutdown
ip route 192.168.3.0 255.255.255.0 10.0.12.2
ip route 192.168.3.0 255.255.255.0 10.0.13.2 5
ipv6 route 2001:db8:3::/64 2001:db8:12::2
ipv6 route 2001:db8:3::/64 2001:db8:13::3 5

--- R2 ---
hostname R2
ipv6 unicast-routing
interface gi0/0
 ip address 10.0.12.2 255.255.255.252
 ipv6 address 2001:db8:12::2/64
 no shutdown
interface gi0/1
 ip address 10.0.23.1 255.255.255.252
 ipv6 address 2001:db8:23::1/64
 no shutdown
ip route 192.168.1.0 255.255.255.0 10.0.12.1
ip route 192.168.3.0 255.255.255.0 10.0.23.2
ipv6 route 2001:db8:1::/64 2001:db8:12::1
ipv6 route 2001:db8:3::/64 2001:db8:23::3

--- R3 ---
hostname R3
ipv6 unicast-routing
interface gi0/0
 ip address 10.0.23.2 255.255.255.252
 ipv6 address 2001:db8:23::3/64
 no shutdown
interface gi0/1
 ip address 192.168.3.1 255.255.255.0
 ipv6 address 2001:db8:3::1/64
 no shutdown
interface gi0/2
 ip address 10.0.13.2 255.255.255.252
 ipv6 address 2001:db8:13::3/64
 no shutdown
ip route 0.0.0.0 0.0.0.0 10.0.23.1
ip route 0.0.0.0 0.0.0.0 10.0.13.1 5
ipv6 route ::/0 2001:db8:23::1
ipv6 route ::/0 2001:db8:13::1 5
